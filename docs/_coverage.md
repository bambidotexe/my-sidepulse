# Coverage manifest

Working file for the 2026-09-19 audit. Records who read what, on which model
and effort, before any deletion is allowed.

## Project membership

SwiftPM only (`Package.swift`, swift-tools 5.10, macOS 14). No Xcode project,
no storyboards/XIBs, no bridging headers, no firmware tree, no CI, no checked-in
Info.plist or entitlements (the bundle's Info.plist is generated by
`scripts/make-app.sh`; the launch-agent plist is generated by
`LoginService.swift`). Targets are directory-based, so membership is
"every `.swift` under the target directory":

| Target | Kind | Directory | Depends on |
|---|---|---|---|
| MySidepulseCore | library | Sources/MySidepulseCore | — |
| MySidepulsePlatform | library | Sources/MySidepulsePlatform | Core |
| MySidepulseApp | executable | Sources/MySidepulseApp | Core, Platform |
| MySidepulseCLI | executable (`mysidepulse`) | Sources/MySidepulseCLI | Core, Platform |
| MySidepulseCoreTests | test | Tests/MySidepulseCoreTests | Core |
| MySidepulsePlatformTests | test | Tests/MySidepulsePlatformTests | Platform, Core |

Orphans, disk → project: none (every `.swift` on disk sits in a target
directory). Orphans, project → disk: none (no target without sources).

Untracked on disk, out of scope: `.build/` (SwiftPM output), `build/`
(generated bundle, icon set — binaries/images), `.git/`,
`.superpowers/sdd/.gitignore` (empty tool scaffold),
`.claude/settings.local.json` and `.claude/agents/*` (session tooling,
git-ignored).

## Worker routing

The Agent tool takes `model` but not `effort`, so both are pinned in
git-ignored agent definitions under `.claude/agents/` and workers are spawned
only through those:

| sp-reader-haiku-low | haiku | low | Read, Grep, Glob |
| sp-reader-sonnet-low | sonnet | low | Read, Grep, Glob |

Routing override: the file-list / membership pass was done by the parent with
two shell commands instead of a Haiku worker — the project is SwiftPM with
directory-based targets, so there is no pbxproj to reconcile.
